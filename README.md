# Mini Browser (8 Mini Browsers)

A multi-view Android web browser built with **Jetpack Compose**, **Material Design 3**, and hardware-accelerated **WebViews**.

## Features

- **Simultaneous Browsing**: View up to 8 interactive web slots in a customizable grid or single-column feed.
- **Fullscreen Mode**: Expand any slot into a full-screen view with a single tap, with web history navigation (Back/Forward), Desktop/Mobile mode toggle, reload, and external launch.
- **Reload All (↻ ВСЕ)**: Instant single-tap reload of all active web slots simultaneously.
- **URL & Search Integration**: Auto-formats input as direct URLs or searches via Google.
- **Custom Presets**: Quick-load curated preset bundles for Social, Dev & Tech, News & Media, or custom slot counts (2, 4, 6, 8 slots).
- **Smooth Gestures & Scrolling**: Touch delegation prevents conflicts between WebView contents and parent scroll containers.
- **Dark Theme**: Eye-safe Material 3 dark interface with custom adaptive icons.
