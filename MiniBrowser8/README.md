# 8 Mini Browsers

Android-приложение с 8 окнами WebView, расположенными сеткой 2×4 (2 колонки, 4 ряда).
В каждом окне можно вписать/заменить свою ссылку и открыть её кнопкой **Go**.
У каждого окна есть кнопки «назад», «вперёд», «обновить» и кнопка **⛶** —
разворачивает это окно на весь экран; кнопка **🗗** в развёрнутом режиме
сворачивает окно обратно на исходное место в сетке.
